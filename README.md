# MuhammedMusabMuratoglu_251109048_WebProjesi

## Proje açıklaması
Teknoloji Haber Sitesi projesi

## Kullanılanlar
- PHP
- MySQL
- HTML
- CSS
- FontAwesome

## Kurulum Adımları

1. Proje dosyalarını XAMPP içindeki `htdocs` klasörüne koyun
2. Apache ve MySQL'i başlatın
3. phpMyAdmin'e girin
4. `proje.sql` dosyasını içe aktarın
5. `veritabani.php` dosyasındaki database bilgilerini kontrol edin:
   - host: localhost
   - dbname: proje
   - user: root
   - password: (boş)

6. Tarayıcıda açın:
   http://localhost/proje/index.php
   "proje" adında database yaratın
   importa basıl proje.sql'i seçin

   ## Özellikler
- Haber listeleme
- Admin paneli
- Admin giriş sistemi (session)
- Haber ekleme / silme
- Kategori sistemi
